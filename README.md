# TicketHub

## Sobre o projeto

O TicketHub é uma plataforma SaaS para criação, gestão e comercialização de ingressos para eventos.

## Objetivo

O objetivo é desenvolver uma solução completa para organizadores publicarem eventos, configurarem tipos de ingresso e acompanharem as operações da plataforma.

## Objetivos técnicos

Além do desenvolvimento da aplicação, este projeto tem como objetivo aplicar boas práticas de engenharia de software, incluindo modelagem de domínio, arquitetura escalável, testes automatizados, documentação, integração contínua e observabilidade.

## Arquitetura

O backend utiliza a arquitetura Package by Feature, organizando o código por domínio de negócio. Essa abordagem aumenta a coesão, facilita a manutenção e permite a evolução gradual para uma arquitetura baseada em microsserviços, caso o crescimento do produto justifique essa mudança.
